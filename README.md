# ไม่รกจอ Pic to PDF by Chang 📄🖼️

โปรแกรมแปลงรูปภาพจากอินเทอร์เน็ต (URL) หรือจากในเครื่อง ลงบนหน้ากระดาษขนาดต่างๆ ที่ต้องการ จัดวางแบบตาราง Grid หลายรูปต่อหน้า สั่งพิมพ์ตรงจากหน้าเว็บได้ทันที หรือบันทึกเป็นไฟล์ PDF คุณภาพสูง

🌐 **ใช้งานจริงบน Cloud ได้ทันทีที่:** [https://mai-rok-jo-pdf.onrender.com](https://mai-rok-jo-pdf.onrender.com)

---

## จุดเด่นและฟังก์ชันการทำงานทั้งหมด

1. **ดึงรูปจาก URL ได้ทันที หรืออัปโหลดจากเครื่อง**:
   - จำลอง Browser User-Agent เพื่อให้ดาวน์โหลดภาพได้ไม่ติดปัญหา 403 Forbidden หรือ CORS
   - รองรับการวางทีละหลาย URL (1 บรรทัดต่อ 1 ลิงก์) หรือเลือกอัปโหลดหลายไฟล์พร้อมกัน
   - แปลงภาพพื้นหลังโปร่งใส (PNG/WEBP Alpha) ลงบนพื้นหลังสีขาวอัตโนมัติ ภาพไม่ดำ
2. **ลากรูปสลับตำแหน่งได้อย่างอิสระ (Drag & Drop Reordering)**:
   - สามารถคลิกค้างแล้วลากรูปเพื่อสลับลำดับในแกลเลอรีได้ทันที
   - มีปุ่มลูกศร `[◀]` และ `[▶]` ให้กดขยับตำแหน่งซ้าย-ขวาได้สะดวกรวดเร็ว
   - เลขลำดับและหน้าพรีวิวจำลองจะอัปเดตตามลำดับใหม่ทันทีแบบ Real-time
3. **จัดหลายรูปต่อหน้า (Pic Per Page & Grid Columns)**:
   - ตัวเลือกจัดวางแบบตาราง Grid:
     - **1 รูป/หน้า (1×1)**: มาตรฐานเต็มหน้า
     - **2 รูป/หน้า (1×2 หรือ 2×1)**: 2 รูปต่อแผ่น (แนวตั้ง/แนวนอน)
     - **4 รูป/หน้า (2×2)**: กริด 4 รูปยอดนิยม
     - **6 รูป/หน้า (2×3 หรือ 3×2)**: 6 รูปต่อแผ่น
     - **9 รูป/หน้า (3×3)**: 9 รูปต่อแผ่น
     - **กำหนดเอง (Custom)**: ระบุจำนวนคอลัมน์ (Cols) × แถว (Rows) เองได้อิสระ
   - ปรับระยะห่างระหว่างรูป (Gap) ได้ เช่น 0 มม., 2 มม., 5 มม., 10 มม.
   - แบ่งหน้าอัตโนมัติ (Auto-Pagination): หากมีรูปมากกว่าจำนวนช่องต่อหน้า ระบบจะแบ่งเป็นหลายหน้าให้อัตโนมัติพร้อมปุ่มเปิดดูแต่ละหน้า
4. **ระบบสั่งพิมพ์จากหน้าเว็บได้ทันที (Direct Print 🖨️)**:
   - มีปุ่ม **"🖨️ สั่งพิมพ์ทันที"** เปิดหน้าต่างพิมพ์ของเบราว์เซอร์ (`window.print()`) ทันทีโดยไม่ต้องรอดาวน์โหลดไฟล์
   - ปรับแต่ง CSS `@page` ให้ตรงกับขนาดกระดาษจริงและระยะขอบที่เลือก สามารถสั่งออกเครื่องปริ้นท์หรือ Save as PDF ได้ทันที
5. **โหมดสว่างและโหมดมืด (Light / Dark Theme ☀️🌙)**:
   - มีปุ่มสลับธีมที่มุมบนขวา จดจำสถานะล่าสุดผ่าน LocalStorage อัตโนมัติ
6. **รองรับขนาดกระดาษยอดนิยมครบครัน**:
   - **ISO**: A3, A4, A5, A6, B4, B5
   - **US Standards**: US Letter, US Legal, Tabloid
   - **ขนาดรูปถ่าย (Photo)**: 4x6 นิ้ว, 5x7 นิ้ว, 8x10 นิ้ว, จัตุรัส (Square)
   - **กำหนดขนาดเอง (Custom Size)**: ระบุความกว้างและความสูงเป็น มม. (mm) หรือ นิ้ว (inch)
7. **ทิศทางและการวางภาพ**: ปรับเลือกแนวตั้ง (Portrait) หรือ แนวนอน (Landscape) และโหมด Fit (พอดีช่องคงสัดส่วน), Fill (เต็มช่องตัดขอบ), Stretch (ยืดเต็มขอบ)
8. **กำหนดระยะขอบกระดาษ (Margins)**: ไร้ขอบ (0 mm), 5 mm, 10 mm, 15 mm, 20 mm หรือระบุขนาดเอง

## วิธีใช้งาน

### วิธีที่ 1: บน Windows (ใช้งานทั่วไป)
1. ดับเบิลคลิกที่ไฟล์ **`run.bat`**
2. ระบบจะเปิดหน้าต่างเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:5500`
3. ใช้งานได้ทันที

---

### วิธีที่ 2: บน Home Server (MacBook M1 / macOS / Linux) 🍏
โปรเจกต์นี้กินทรัพยากรต่ำมาก (RAM ~50-80 MB, กินไฟเพียง 3-5 วัตต์) เหมาะมากสำหรับการเปิดทิ้งไว้เป็น Home Server:

1. คัดลอกโฟลเดอร์นี้ไปที่ Mac *(ไม่ต้องคัดลอกโฟลเดอร์ `.venv` ไปด้วย)*
2. ติดตั้ง `uv` บน Mac (ทำครั้งเดียว):
   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   ```
3. สั่งรันโปรแกรม:
   ```bash
   cd "path/to/pic to pdf"
   chmod +x run.sh
   ./run.sh
   ```
4. **เข้าใช้งานจากมือถือ / iPad / คอมเครื่องอื่นในบ้าน**:
   - เปิดเบราว์เซอร์ไปที่ IP ของเครื่อง Mac เช่น `http://192.168.1.50:5500` (ระบบจะแสดงเลข IP ให้เห็นบน Terminal ทันที)

> 📖 ดูคู่มือการตั้งค่าแบบละเอียด (การพับจอไม่ให้หลับ, การถนอมแบตเตอรี่, การรัน Auto-Start) ได้ที่ไฟล์ **[HOME_SERVER_MAC_M1.md](HOME_SERVER_MAC_M1.md)**

---

### วิธีที่ 3: นำขึ้น Cloud Hosting ฟรี (เช่น Render.com) ☁️
หากไม่อยากเปิดคอมพิวเตอร์ทิ้งไว้ที่บ้าน สามารถนำขึ้น Cloud Hosting ได้ฟรี:
1. นำโค้ดขึ้น GitHub
2. สมัครใช้งานที่ [Render.com](https://render.com/) และเลือกสร้าง **Web Service**
3. ระบบจะอ่านการตั้งค่าจาก `requirements.txt` และ `render.yaml` ให้อัตโนมัติ ได้ลิงก์ใช้งานจริง เช่น `https://xxxx.onrender.com`

> 📖 ดูคู่มือการนำขึ้น Cloud ฟรีทีละขั้นตอนได้ที่ไฟล์ **[CLOUD_DEPLOY_GUIDE.md](CLOUD_DEPLOY_GUIDE.md)**

---

### วิธีที่ 4: สั่งงานผ่าน Command Line (CLI)

สามารถสั่งการผ่าน Terminal ได้โดยตรง เช่น:

```bash
# แปลงรูปภาพลงกระดาษ A4 แนวตั้ง ขอบ 10 มม.
uv run python pic_to_pdf.py -u "https://images.unsplash.com/photo-1506744038136-46273834b3fb" -s A4 -o portrait -m 10 -out "my_a4.pdf"

# จัด 4 รูปลงบนกระดาษ A4 ในตาราง 2x2
uv run python pic_to_pdf.py -u "url1.jpg" -u "url2.jpg" -u "url3.jpg" -u "url4.jpg" -s A4 --cols 2 --rows 2 --gap 5 -out "grid_2x2.pdf"

# จัด 6 รูปลงกระดาษ A3 แนวนอน โหมดเต็มช่อง (Fill)
uv run python pic_to_pdf.py -u "url1.jpg" -u "url2.jpg" -u "url3.jpg" -u "url4.jpg" -u "url5.jpg" -u "url6.jpg" -s A3 -o landscape --cols 3 --rows 2 --fit fill -out "poster_a3.pdf"
```

## โครงสร้างไฟล์ในโครงการ

```
pic to pdf/
├── run.bat                 # ดับเบิลคลิกเปิดโปรแกรมทันทีบน Windows
├── run.sh                  # สคริปต์เปิดโปรแกรมบน macOS (M1/M2/M3) และ Linux
├── HOME_SERVER_MAC_M1.md   # คู่มือการรันเป็น Home Server บน Mac M1
├── CLOUD_DEPLOY_GUIDE.md   # คู่มือการนำขึ้น Cloud Hosting ฟรี (Render / Koyeb)
├── README.md               # คู่มือการใช้งานภาพรวม
├── app.py                  # เซิร์ฟเวอร์ Web UI & API Backend
├── pic_to_pdf.py           # Core Engine & CLI สำหรับคำนวณและสร้าง PDF
├── web/
│   └── index.html          # หน้าเว็บ UI (รองรับ Drag & Drop, Grid, Print, Light/Dark)
├── requirements.txt        # รายการแพ็กเกจสำหรับ Cloud Deployment
├── Dockerfile              # สำหรับ Deploy ผ่าน Container
├── render.yaml             # ไฟล์ตั้งค่าสำหรับ Render.com อัตโนมัติ
├── output/                 # โฟลเดอร์เก็บไฟล์ PDF ที่สร้างเสร็จ
└── pyproject.toml          # การตั้งค่า dependencies
```
